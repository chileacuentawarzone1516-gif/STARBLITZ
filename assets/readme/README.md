# Recursos del README

Aquí viven los recursos gráficos que usa el [README](../../README.md).

| Recurso | Estado |
|---|---|
| `icons/*.svg` (iconos de las tarjetas de características) | Creados con la paleta de STARBLITZ |
| **Banner** (`banner-dark.svg`, `banner-light.svg`) | **Pendiente**: requiere el archivo original del logo oficial (rombo de cristal azul y morado) |
| **Imagen social** (`social-preview.png`, 1280×640) | **Pendiente**: requiere el mismo archivo original |

> No se debe sustituir el logo oficial por otra marca ni redibujarlo. Cuando se disponga del archivo original (SVG o PNG
> de al menos 1024 px con fondo transparente), el banner se generará con la paleta oficial y el lema
> «Translate beyond words.», con el texto convertido a trazados (GitHub no carga fuentes externas en imágenes SVG).
